Auf der Karte, ohne ständiges Warten, reproduzierbar (26.10.2026)

{% with k=karte %}

Ein Schritt rechnet in einem Prozess auf der Grafikkarte; die CPU soll nur Rechnungen anstoßen, nicht nach jeder auf das Ergebnis warten. Drei Dinge gehören dazu:

  1. Was auf der CPU rechnete, rechnet auf der Karte: Rendern in torch statt pyrender (Kostuemraster, nach dem Quelltext von pyrender: MSAA 4×, die vier Abtastpunkte vom Treiber gelesen), Löcher füllen und Inseln zählen ohne scipy (Kostuemmaske), das Bild für ViTPose, die Tafeln von Formmass2.
  2. Keine Wartepunkte in den Schleifen: Ein Index mit Maske (x[maske]) wartet im Vor- und Rückweg auf die Karte (nur sie kennt die Zahl der Treffer) — ersetzt durch einen Index, einmal mit nonzero gebaut; if tensor und float(t) nur noch in der Auswertung. Körper- und Kopfschleife laufen als CUDA-Graph: ein Schritt wird einmal aufgenommen und dann als Ganzes wiedergegeben (Körper GRAPH = {{ k.graph.koerper|yesno:"an,aus,—" }}, Kopf GRAPH = {{ k.graph.kopf|yesno:"an,aus,—" }}).
  3. Reproduzierbar: Ohne Schalter rechnete derselbe Code in zwei Prozessen verschieden (Summen in wechselnder Reihenfolge auf der Karte). Determinismus schaltet in jedem Prozess der Kette torch deterministisch, cuDNN ohne Autotuning und feste Samen ({{ k.samen|default:"—" }}) ein — über die Umgebung {% for n, w in k.umgebung.items %}{{ n }}={{ w }}{% if not forloop.last %}, {% endif %}{% endfor %}, die {% if k.lauf_setzt %}der Rechenlauf für jeden Schritt setzt{% else %}der Rechenlauf NICHT setzt{% endif %}; Kindprozesse erben sie.
